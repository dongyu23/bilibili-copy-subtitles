# Bilibili 一键复制全部字幕

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-用户脚本-00485b?logo=tampermonkey)](https://www.tampermonkey.net/)
[![Version](https://img.shields.io/badge/version-1.6.0-00aeec)](./bilibili-copy-subtitles.user.js)
[![License](https://img.shields.io/badge/license-MIT-green)](./LICENSE)

一个轻量的 Bilibili 油猴脚本。打开有字幕的视频，点击页面左下角的 **复制全部字幕**，即可把整理后的纯文字字幕复制到剪贴板。

复制结果保留正文标点，不包含时间戳、字幕序号、JSON 字段或其他字幕文件边界符号，适合整理笔记、检索内容和制作摘要。脚本会按当前视频和分 P 缓存字幕列表及正文，重复读取时不会重新随机匹配其他视频的字幕。对于没有字幕的视频，可以在设置 StepFun API Key 后回退到语音识别，自动生成可复制的纯文字内容。

## 安装

安装前需要浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/) 或其他兼容 UserScript 的脚本管理器。

### 一键安装

[点击安装脚本](https://raw.githubusercontent.com/dongyu23/bilibili-copy-subtitles/main/bilibili-copy-subtitles.user.js)

Tampermonkey 打开安装确认页后，点击“安装”即可。脚本后续可以通过脚本管理器自动检查更新。

### 手动安装

1. 打开 Tampermonkey 管理面板。
2. 新建脚本并删除编辑器中的默认内容。
3. 将 [`bilibili-copy-subtitles.user.js`](./bilibili-copy-subtitles.user.js) 的全部内容粘贴进去。
4. 保存脚本并刷新 Bilibili 视频页面。

## 使用

1. 登录 Bilibili。部分视频只有登录后才能读取字幕列表。
2. 打开一个带有字幕的视频。
3. 在页面左下角的语言下拉框中选择字幕语言，默认是 **中文（默认）**，也可以选择英文、日文等其他语言。
4. 点击 **复制全部字幕**。
5. 页面显示复制成功及字符数量后，字幕正文已经进入剪贴板。

也可以从 Tampermonkey 菜单执行“复制当前视频全部字幕”。如果不想显示页面按钮，可以通过菜单中的“显示/隐藏页面按钮”关闭它。

## 功能

- 一键复制当前视频或当前分P的完整字幕
- 自动去除时间戳、序号和字幕格式边界
- 保留字幕正文原有标点
- 中英文相邻字幕行自动补充必要空格
- 支持普通视频、分P、合集、播放列表和番剧播放页
- 无字幕视频可回退到 StepFun 语音识别，生成纯文字内容
- 语音识别 Key 图形化配置面板，支持一键测试连接
- 识别过程可视化：阶段、进度条、实时耗时
- 识别耗时统计：开始前预估、完成后展示实际用时
- 页面按钮支持显示或隐藏
- 原生请求失败时自动尝试油猴跨域请求
- 支持 Tampermonkey 自动更新

## 字幕选择规则

脚本默认优先复制中文字幕；每个视频第一次读取时会加载该视频实际提供的字幕语言列表：

1. 语言代码为中文或 AI 中文的字幕
2. 名称包含“中文”“汉语”“简体”或“繁体”的字幕
3. 非 AI 字幕
4. 如果以上条件均不满足，使用视频提供的第一条字幕

选择过具体语言后，在同一视频分 P 内再次读取会沿用该选择；切换到其他视频或分 P 时会恢复为中文默认选项。

脚本会复用 B 站播放器当前页面已经发出的带签名字幕请求，避免旧接口返回其他视频字幕。字幕按 `bvid/cid/语言` 隔离并保存在当前标签页中，不设置过期时间；在该标签页内重复读取或刷新页面都会复用缓存，关闭标签页后缓存自动清除，不会上传到服务器。

因此，只要视频提供中文字幕，脚本就不会默认选择英文字幕。

## 无字幕视频的语音识别兜底

当视频既没有 UP 主字幕、也没有 B 站 AI 字幕时，脚本可以下载该视频的音频轨道，通过 StepFun 语音识别接口（`stepaudio-2.5-asr`）生成纯文字内容。兜底与字幕链路完全独立，不影响原有行为。

### 开启方式

1. 从 Tampermonkey 菜单执行「设置 StepFun API Key（无字幕视频语音识别）」，在弹出的面板中粘贴 [StepFun 开放平台](https://platform.stepfun.com/interface-key) 的 API Key（需订阅 Step Plan），点击「测试连接」确认可用后「保存」。也可以直接点击无字幕视频的「复制全部字幕」，脚本会自动弹出该面板。
2. 打开无字幕视频，点击 **复制全部字幕**。
3. 首次使用会弹窗确认：将下载音频并上传到 StepFun 识别（会产生费用），确认后开始识别。
4. 识别完成后文字直接进入剪贴板，提示样式与字幕复制一致。

### 进度与耗时

识别过程中页面左下角会显示实时进度面板，包含三个阶段：

- **正在下载音频**：显示已下载/总大小与百分比（通过油猴请求获取真实进度）；
- **正在识别**：显示当前分片（如 `第 1/2 段`），进度按音频时间轴推进（识别接口的增量结果带时间戳）；
- 面板右下角实时显示已用时间，全部阶段统一计时。

确认对话框会根据历史记录给出预估用时；完成后提示中会展示实际用时，例如「已通过语音识别复制，共 3971 个字符 · 用时 13.9 秒」。脚本在本地保留最近 20 次识别的音频时长与耗时，预估随使用越来越准。短于 12 MB 的音频一次请求完成，超过则自动分片、逐片识别。

不配置 Key 时，无字幕视频仍保持原来的「当前视频没有可用字幕」提示，不会产生任何请求。

### 工作方式

- 通过 B 站播放接口（`/x/player/playurl`，番剧为 `/pgc/player/web/playurl`）获取当前分 P 的 DASH 音频流，选择码率最高的普通 AAC 音轨；无签名直连被风控时，自动复用播放器自己发出的带签名请求。
- 下载完整音频后按 MP4 片段（`moof` 边界）分片，每片重新拼上头信息后独立送识别，长视频也不会超限；结果在当前标签页缓存，重复点击不会重复计费。
- 语音识别默认使用 `zh`，可在脚本源码顶部修改 `ASR_LANGUAGE`。
- 计费按音频时长计算（`stepaudio-2.5-asr` 约 0.15 元/小时），具体以 [定价页](https://platform.stepfun.com/docs/zh/guides/pricing/details) 为准。

### 注意事项

- 脚本默认不内置 Key，首次在无字幕视频上点击复制时会自动弹出配置面板；Key 只保存在浏览器本地，不会上传到其他服务器。
- 语音识别会把音频上传到 StepFun，请仅用于有权转写的内容。
- 部分视频（如会员专属音轨）可能拿不到音频流，脚本会提示重新播放后重试。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `GM_setClipboard` | 将整理后的字幕写入剪贴板 |
| `GM_addStyle` | 显示页面按钮和操作提示 |
| `GM_registerMenuCommand` | 提供复制、Key 设置及按钮显示开关 |
| `GM_xmlhttpRequest` | 原生请求失败时读取字幕文件、下载音频 |
| `GM_getValue` / `GM_setValue` | 保存语音识别 API Key |
| `unsafeWindow` | 获取当前视频及分P编号 |
| `api.bilibili.com` | 获取当前视频的字幕列表与音频流地址 |
| `aisubtitle.hdslb.com` | 获取 Bilibili AI 字幕文件 |
| `*.bilivideo.com` | 下载 DASH 音频文件 |
| `api.stepfun.com` | 调用 StepFun 语音识别接口 |

字幕链路不上传任何数据，也不收集浏览记录或统计信息；仅当主动使用语音识别兜底时，音频才会上传至 StepFun 接口。

## 常见问题

### 提示“当前视频没有可用字幕”

该视频可能没有 UP 主字幕或 Bilibili AI 字幕。也可能是账号未登录，登录后刷新页面再试。如需在无字幕时自动生成文字，请参考上文「无字幕视频的语音识别兜底」配置 StepFun API Key。

### 安装新版后行为没有变化

在 Tampermonkey 编辑器中确认脚本顶部的 `@version`。如果仍是旧版本，请删除旧内容后重新点击一键安装链接，并刷新视频页面。

### 点击后显示网络请求失败

确认脚本管理器已经授予 `api.bilibili.com` 和 `aisubtitle.hdslb.com` 的跨域访问权限。升级或重新安装脚本时，Tampermonkey 可能会再次显示权限确认页面。

### 为什么复制结果没有换行

Bilibili 字幕通常按短句切分。脚本会移除这些显示层面的分段并拼接为连续正文，同时保留字幕内容中真正存在的换行。

- **原有字幕链路**：有字幕视频走原路径读取字幕列表、下载字幕文件、清洗后写入剪贴板，未触发任何语音识别请求。
- **语音识别兜底链路**：无字幕视频点击复制后，依次完成播放接口取音频流（3 条 AAC 音轨选取最高码率）、下载 13.1MB 音频、按 MP4 片段自动分 2 片、两段 StepFun SSE 识别后拼接，最终写入剪贴板 `3971` 个字符，内容与视频主题一致；第二次点击命中标签页缓存，未产生新的识别调用。
