# Bilibili / YouTube / 视频号 一键复制全部字幕

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-用户脚本-00485b?logo=tampermonkey)](https://www.tampermonkey.net/)
[![Version](https://img.shields.io/badge/version-2.0.0-00aeec)](./bilibili-copy-subtitles.user.js)
[![License](https://img.shields.io/badge/license-MIT-green)](./LICENSE)

一个轻量的油猴脚本，同时支持 **Bilibili**、**YouTube** 和 **微信视频号**。打开有字幕的视频，点击页面左下角的 **复制全部字幕**，即可把整理后的纯文字字幕复制到剪贴板；视频号则通过分享链接把视频语音转成文字。

复制结果保留正文标点，不包含时间戳、字幕序号、JSON 字段或其他字幕文件边界符号，适合整理笔记、检索内容和制作摘要。脚本会按当前视频和分 P 缓存字幕列表及正文，重复读取时不会重新随机匹配其他视频的字幕。对于没有字幕的视频，可以在设置 StepFun API Key 后回退到语音识别，自动生成可复制的纯文字内容。

## v2.0.0 新特性

- **章节选择**：从播放器接口读取视频章节，识别前可选全篇或自由勾选任意章节组合；没有章节的视频不弹面板，行为与之前完全一致。章节模式下输出带 `【章节名】` 分隔。
- **流式分段识别**：HTTP Range 滑动窗口边下边切，按 moof 边界分片，稳态内存与视频长度无关（7 小时视频从 600MB+ 降到约 50–80MB）。
- **断点续传**：分片级 checkpoint 写入扩展存储，中断后重跑自动跳过已完成分片；油猴菜单可一键清除断点。
- **本页执行 + 内存护栏**：流式分段把内存压到与视频长度无关的低位；另有堆内存看门狗（占用超 60% 暂停等待回收、超 80% 主动中止保护页面），分片间主动让出主线程，识别期间页面保持响应。
- **有界并发**：在途分片总字节设上限，大片自动降并发。

## 安装

安装前需要浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/) 或其他兼容 UserScript 的脚本管理器。

### 一键安装

[点击安装脚本](https://raw.githubusercontent.com/dongyu23/bilibili-copy-subtitles/main/bilibili-copy-subtitles.user.js)

Tampermonkey 打开安装确认页后，点击“安装”即可。脚本后续可以通过脚本管理器自动检查更新。

### 手动安装

1. 打开 Tampermonkey 管理面板。
2. 新建脚本并删除编辑器中的默认内容。
3. 将 [`bilibili-copy-subtitles.user.js`](./bilibili-copy-subtitles.user.js) 的全部内容粘贴进去。
4. 保存脚本并刷新视频页面。

## 使用

1. 打开一个带有字幕的视频（Bilibili 视频/番剧播放页，或 YouTube 视频页）。
2. 在页面左下角的语言下拉框中选择字幕语言，默认是 **中文（默认）**，也可以选择英文、日文等其他语言。
3. 点击 **复制全部字幕**。
4. 页面显示复制成功及字符数量后，字幕正文已经进入剪贴板。

也可以从 Tampermonkey 菜单执行“复制当前视频全部字幕”。如果不想显示页面按钮，可以通过菜单中的“显示/隐藏页面按钮”关闭它。

YouTube 链路通过 YouTube 官方的 InnerTube 播放器接口读取字幕轨与音频直链，无需登录；个别视频可能受所在网络环境能否访问 YouTube 影响。B 站链路不变，部分视频只有登录后才能读取字幕列表。

视频号链路见下文「视频号转文字」：点左下角的 **视频号转文字** 按钮，粘贴分享链接即可。页面左下角还有一个不显眼的齿轮按钮（⚙，鼠标悬停才清晰），点击或从 Tampermonkey 菜单「设置」进入集中设置面板，管理 API Key、识别端点与语言、调试开关、元宝 Cookie 和缓存留存时间。

## 功能

- 一键复制当前视频或当前分P的完整字幕（B站 / YouTube / 视频号 三站点）
- 自动去除时间戳、序号和字幕格式边界
- 保留字幕正文原有标点
- 中英文相邻字幕行自动补充必要空格
- 支持普通视频、分P、合集、播放列表和番剧播放页
- YouTube 字幕轨自动列出全部语言，默认优先中文
- 无字幕视频可回退到 StepFun 语音识别，生成纯文字内容（B站 / YouTube 均支持）
- 视频号转文字：粘贴分享链接即自动完成「解析 → 下载 → 语音识别 → 剪贴板」
- 语音识别 Key 图形化配置面板，支持一键测试连接
- 设置面板集中管理：Key、识别端点、识别语言、调试开关、元宝 Cookie、缓存留存时间
- 识别过程可视化：阶段、进度条、实时耗时
- 识别耗时统计：开始前预估、完成后展示实际用时
- 音频下载失败自动换取新的播放数据地址重试，并依次尝试备用 CDN 地址
- 字幕/识别结果缓存留存时间可配置（会话 / 1 小时 / 24 小时 / 7 天 / 30 天 / 永久）
- 页面按钮支持显示或隐藏
- 原生请求失败时自动尝试油猴跨域请求
- 支持 Tampermonkey 自动更新

## 字幕选择规则

脚本默认优先复制中文字幕；每个视频第一次读取时会加载该视频实际提供的字幕语言列表：

1. 语言代码为中文或 AI 中文的字幕
2. 名称包含“中文”“汉语”“简体”或“繁体”的字幕
3. 非 AI 字幕
4. 如果以上条件均不满足，使用视频提供的第一条字幕

选择过具体语言后，在同一视频分 P 内再次读取会沿用该选择；切换到其他视频或分 P 时会恢复为中文默认选项。

B 站会复用播放器当前页面已经发出的带签名字幕请求，避免旧接口返回其他视频字幕。YouTube 则按视频 ID 直接请求官方播放器接口，字幕列表与语言名称以接口返回为准。

## 缓存与留存时间

字幕列表、字幕正文和语音识别结果都按 `视频:分P:语言` 隔离缓存，重复点击不会重复下载或重复计费。缓存的留存时间可以在 Key 配置面板中调整：

| 选项 | 行为 |
| --- | --- |
| 仅本次会话（默认） | 刷新页面保留，关闭标签页后清除 |
| 1 小时 / 24 小时 / 7 天 / 30 天 | 写入浏览器本地存储，超过对应时间后自动失效 |
| 永久 | 一直保留，直到手动清除 |

打开 Tampermonkey 菜单的「设置 StepFun API Key 与缓存」即可修改留存时间、查看已缓存条目数，也可以一键清除全部字幕缓存。缓存只保存在浏览器本地，不会上传到服务器。

## 无字幕视频的语音识别兜底

当视频没有任何字幕时，脚本可以下载该视频的音频轨道，通过 StepFun 语音识别接口（`stepaudio-2.5-asr`）生成纯文字内容。兜底与字幕链路完全独立，不影响原有行为。

### 开启方式

1. 从 Tampermonkey 菜单执行「设置 StepFun API Key（无字幕视频语音识别）」，在弹出的面板中粘贴 [StepFun 开放平台](https://platform.stepfun.com/interface-key) 的 API Key（需订阅 Step Plan），点击「测试连接」确认可用后「保存」。也可以直接点击无字幕视频的「复制全部字幕」，脚本会自动弹出该面板。
2. 打开无字幕视频，点击 **复制全部字幕**。
3. 首次使用会弹窗确认：将下载音频并上传到 StepFun 识别（会产生费用），确认后开始识别。
4. 识别完成后文字直接进入剪贴板，提示样式与字幕复制一致。

### 进度与耗时

识别过程中页面左下角会显示实时进度面板，包含三个阶段：

- **正在下载音频**：显示已下载/总大小与百分比（通过油猴请求获取真实进度）；
- **正在识别**：多分片时显示并行状态（如 `并行 3 段 · 已完成 1/4 段`），进度按音频时间轴推进（识别接口的增量结果带时间戳）；
- 面板右下角实时显示已用时间，全部阶段统一计时。

确认对话框会根据历史记录给出预估用时；完成后提示中会展示实际用时，例如「已通过语音识别复制，共 3971 个字符 · 用时 13.9 秒」。脚本在本地保留最近 20 次识别的音频时长与耗时，预估随使用越来越准。短于 12 MB 的音频一次请求完成，超过则自动分片、最多 3 片并行识别（并发数见源码 `ASR_CONCURRENCY`）。

不配置 Key 时，无字幕视频仍保持原来的「当前视频没有可用字幕」提示，不会产生任何请求。

### 工作方式

- **B 站**：通过播放接口（`/x/player/playurl`，番剧为 `/pgc/player/web/playurl`）获取当前分 P 的 DASH 音频流，选择码率最高的普通 AAC 音轨；无签名直连被风控时，自动复用播放器自己发出的带签名请求。
- **YouTube**：通过 InnerTube 播放器接口（Android 客户端上下文）获取音频直链，选择体积最小的 m4a 音轨以控制请求体大小，同一响应中的其他 m4a 地址作为备用 CDN。
- 下载完整音频后按 MP4 片段（`moof` 边界）分片，每片重新拼上头信息后独立送识别，多片同时上传、结果按原顺序拼接，长视频也不会超限；结果按缓存策略保留，重复点击不会重复计费。
- 音频地址全部下载失败时（直链过期、CDN 节点拒绝等），脚本会自动重新拉取播放数据换取新地址再试，仍失败才提示错误。
- 语音识别默认使用 `zh`，可在脚本源码顶部修改 `ASR_LANGUAGE`。实际接口对中英文音频均可转写。
- 计费按音频时长计算（`stepaudio-2.5-asr` 约 0.15 元/小时），具体以 [定价页](https://platform.stepfun.com/docs/zh/guides/pricing/details) 为准。

### 注意事项

- 脚本默认不内置 Key，首次在无字幕视频上点击复制时会自动弹出配置面板；Key 只保存在浏览器本地，不会上传到其他服务器。
- 语音识别会把音频上传到 StepFun，请仅用于有权转写的内容。
- 部分视频（如会员专属音轨）可能拿不到音频流，脚本会提示重新播放后重试。

## 视频号转文字

微信视频号没有可复制的字幕接口，脚本通过「元宝解析分享链接 → 获取视频直链 → 语音识别」把视频语音转成文字，全程无需安装其他软件、不修改系统代理。

### 使用方式

1. 点页面左下角的 **视频号转文字** 按钮（B 站 / YouTube / 视频号页面都能看到；在视频号页面会自动带入当前视频的短链）。
2. 粘贴视频号分享链接（在微信里点视频右上角 `・・・` → 复制链接，形如 `https://weixin.qq.com/sph/xxxx`），点 **开始转文字**。
3. 首次使用会弹窗确认（音频会上传至 StepFun，按时长计费）。
4. 进度面板依次显示「解析分享链接 → 获取视频信息 → 下载视频 → 识别」，完成后文字自动进入剪贴板，并显示在面板文本框中可再次复制。

### 前置配置（一次性）

- **StepFun API Key**：与另外两个站点共用，在设置面板填写。
- **元宝 Cookie**：点设置面板里的 **打开元宝** 按钮并扫码登录，然后点 **一键读取 Cookie** 即可自动读取全部字段（含 HttpOnly，已自动过滤统计类参数）并保存。若自动读取不可用（非 Tampermonkey 管理器），再按 `F12` → `Application/应用` → `Cookies` → `yuanbao.tencent.com` 全选复制，粘贴到设置面板的「元宝 Cookie」输入框。Cookie 过期后按同样方式更新即可。
- 两个接口都要求在浏览器环境内调用（服务端有 TLS 指纹校验），因此必须通过油猴脚本发起，不能用命令行工具替代。

### 工作方式与限制

- 小于 20MB 的视频整包送给 StepFun（接口原生支持 MP4 容器，由服务端提取音频，无需本地 ffmpeg）；超过则用浏览器内置解码器提取 16kHz 单声道音频后分片送识别。
- 已加密的视频号视频暂不支持（脚本会明确提示），未加密的常规视频可直接转换。
- StepFun 单次请求上限约 30 分钟音频；更长的视频需要分段处理。
- 转写结果按视频缓存，重复点击同一链接不会重复计费。

## 常见问题

### 提示“当前视频没有可用字幕”

该视频可能没有 UP 主字幕或 Bilibili AI 字幕（YouTube 则可能没有字幕轨）。也可能是账号未登录，登录后刷新页面再试。如需在无字幕时自动生成文字，请参考上文「无字幕视频的语音识别兜底」配置 StepFun API Key。

### YouTube 页面没有反应

确认当前网络可以访问 YouTube。脚本只读取公开的播放器接口，不需要登录；如果网络本身无法连接 YouTube，脚本会提示读取失败。

### 安装新版后行为没有变化

在 Tampermonkey 编辑器中确认脚本顶部的 `@version`。如果仍是旧版本，请删除旧内容后重新点击一键安装链接，并刷新视频页面。

### 点击后显示网络请求失败

确认脚本管理器已经授予对应站点的跨域访问权限（B 站为 `api.bilibili.com` 和 `aisubtitle.hdslb.com`）。升级或重新安装脚本时，Tampermonkey 可能会再次显示权限确认页面。

### 语音识别提示“音频下载失败”

音频直链可能已过期或被 CDN 节点拒绝，脚本会自动换取新地址重试；多次重试仍失败时，请稍后重试或更换视频。个别网络环境（代理、公司网络）可能拦截视频 CDN，需要切换网络后重试。

### 视频号提示“元宝解析失败”

元宝 Cookie 已过期或复制不完整（需包含 HttpOnly 项）。按「视频号转文字 → 前置配置」的步骤重新获取并粘贴到设置面板。

### 视频号提示“该视频已加密”

该视频号内容启用了加密，暂不支持自动转写，换用未加密的常规视频即可。

### 为什么复制结果没有换行

字幕通常按短句切分。脚本会移除这些显示层面的分段并拼接为连续正文，同时保留字幕内容中真正存在的换行。
